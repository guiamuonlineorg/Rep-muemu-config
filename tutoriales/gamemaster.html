10. Cómo crear un GameMaster

Un GameMaster (GM) es el administrador dentro del juego. Tendrá una marca sobre la cabeza con el logo de "GM", y permisos para usar comandos invisibles, mover a otros jugadores o crear ítems. En MuEmu no hace falta tocar la base de datos SQL para hacer esto.

1. Ubicar el sistema de Rangos

Muserver / Data / Util / GMSystem.txt (o Command.dat en algunas versiones)

2. Añadir a tu Personaje

Al abrir el archivo, verás una sección donde puedes declarar los nombres exactos de los personajes. Debe lucir de esta manera:

// Rango (1 a 3) Nombre del PJ
32 "AdminEnzo"

El número 32 (o 1, dependiendo la temporada de tu MuEmu) le otorga el nivel más alto de bandera (Flag) de administrador.

3. Comandos Útiles

Una vez que recargues el servidor, tu personaje podrá usar (dependiendo de la configuración):

  • /make 0 0 15 1 (Crea un arma de la categoría 0, index 0, nivel +15, con skill).
  • /gmove AdminEnzo 0 125 125 (Mueve a un personaje, incluyéndote, a un mapa específico).
  • /trace NombrePJ (Te teletransporta automáticamente al lado del personaje elegido, útil para atrapar hackers).
  • /dc NombrePJ (Desconecta forzosamente al personaje).
