9. Configuración del Sistema VIP

El sistema VIP es la principal fuente de ingresos de un servidor. Puedes definir hasta 3 niveles de VIP (Plata, Oro, Platino), dándole ventajas únicas a los jugadores que colaboran económicamente.

1. Ubicar el Archivo VIP

Muserver / GameServer / Data / GameServerInfo - Vip.dat

2. Modificar Ventajas Base

En este archivo encontrarás multiplicadores exclusivos para los usuarios VIP. Los valores más importantes son:

// Porcentaje de Experiencia adicional al matar monstruos
AddExperienceVIP1 = 150
AddExperienceVIP2 = 200

// Posibilidad extra de hacer ítems en la Máquina Chaos
ChaosMixPlus10VIP1 = 10 // (Suma un 10% de éxito extra)

3. Entradas al Servidor Especiales

En MuEmu puedes configurar para que un Sub-Servidor sea "Solo VIP". Esto se hace en el archivo de configuración del GameServer en la ruta de inicio, configurando ServerVIP = 1. Los usuarios sin suscripción verán que al intentar conectar les dice "Servidor Exclusivo".
