Básico

Gestión de Comandos (/post, /add, /reset)

Los comandos facilitan la vida del jugador, permitiéndoles repartir stats, hablar globalmente o resetear su personaje sin salir del juego. En MuEmu, todo esto es altamente configurable.

1. Ubicando el Archivo de Comandos

Muserver / GameServer / Data / GameServerInfo - Command.dat

2. Activar Comandos y Costos

Dentro del archivo verás secciones para cada comando. Por ejemplo, la configuración del comando Global (/post):

CommandPostSwitch = 1
CommandPostType = 0
CommandPostMoney = 100000
CommandPostLevel = 50
  • Switch: Coloca 1 para habilitarlo o 0 para desactivarlo del servidor.
  • Money: ¿Cuánto Zen costará usar el comando? Sirve para controlar la economía.
  • Level: Nivel mínimo requerido para usarlo (Ideal para evitar Spam de personajes nuevos).

3. Comandos de Reparto de Stats

Puedes configurar los comandos /addstr (Fuerza), /addagi (Agilidad), etc. Una opción muy buscada es si requiere reloguear (salir y entrar) para que los stats surtan efecto:

CommandAddPointAutoEnable = 1

Al poner esta línea en 1, cuando el jugador escriba /addstr 500, los puntos se sumarán y el daño se actualizará inmediatamente sin reloguear.
