Cómo configurar la Experiencia y el Drop General

En esta guía aprenderás a ajustar la dificultad principal de tu servidor. Esta configuración define cuánta experiencia ganan los personajes al derrotar monstruos y qué tan frecuente es la caída de ítems generales y Zen.

1. Ubicando el Archivo Correcto

Todos los parámetros generales de jugabilidad se manejan en un archivo principal del GameServer. Ve a tu VPS o computadora host y sigue esta ruta exacta:

Muserver / GameServer / Data / GameServerInfo - Common.dat

2. Modificando la Experiencia (EXP)

Abre el archivo Common.dat con el Bloc de notas o Notepad++. Busca la sección llamada [GameServerInfo]. Debajo encontrarás la línea de experiencia.

// Experiencia Base del servidor
AddExperience = 100
  • Hard (Difícil): Configura entre 1 y 50.
  • Medium (Medio): Configura entre 100 y 500.
  • Fast/Fun (Fácil): Configura entre 1000 y 9999.

3. Modificando el Drop (Caída de Ítems)

En el mismo archivo, un poco más abajo, encontrarás la variable del Drop. Este número representa un porcentaje de éxito general para que los monstruos suelten "algo" al morir (ítems o zen).

// Porcentaje de Drop (0 a 100)
ItemDropPer = 50
Pro Tip: Sistemas VIP

Si tu servidor tiene sistema VIP activado, recuerda buscar las líneas AddExperienceVIP (VIP 1, 2 y 3) dentro del mismo archivo para darle un porcentaje extra a los usuarios que apoyan tu servidor con suscripciones.

4. Aplicando los Cambios sin Reiniciar

Una de las mejores ventajas de MuEmu es que no necesitas apagar el servidor (GameServer) para que estos cambios tengan efecto.

  1. Guarda el archivo Common.dat (Ctrl + S).
  2. Abre la ventana negra del GameServer en tu VPS.
  3. En el menú superior de esa ventana, haz clic en Reload (Recargar).
  4. Selecciona la opción Common.

¡Listo! Los jugadores verán el cambio de experiencia en tiempo real tras matar al siguiente monstruo.
